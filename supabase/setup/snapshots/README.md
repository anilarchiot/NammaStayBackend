# Historical SQL snapshots

The numbered files in `2026-10-16/` are a point-in-time full-schema export, not
the active migration stream. Files in `legacy-root/` are older setup bundles
and checks retained for reference.

For a new or existing Supabase project, use the ordered files in
`../../migrations/` and the current checks in `../checks/`. Do not run these
snapshots on a live database.
